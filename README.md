## 收录内容

| 分类 | 内容 |
| --- | --- |
| 免费版 | 2.x / 3.x / 4.x，32 位和 64 位；ISO、IMG、GHO、BIN、PATCH |
| 企业版 | 3.x 及 4.x Beta，x32 / x64；不同版本及 Build 分开保存 |
| OEM | 已知可下载的 OEM 固件 |
| 硬件固件 | 路由器、AP、交换机、防火墙等设备固件 |
| 工具与资料 | 官方云盘的工具、虚拟机镜像、使用手册、教程及产品素材 |

同一版本的不同架构和格式放在一起；不同 Build 分开保存。
固件按 Build 时间倒序排列，无日期的工具和资料放在末尾。

## 下载

打开 [Releases](https://github.com/LOVECHEN/ikuai-release/releases)，按版本或类别查找文件。中文资料采用可读的英文文件名，每个 Release 内提供“原始中文名 → 英文文件名”对照表，可直接点击下载。

每个分组附带 `checksums.sha256` 校验文件及 `sources.json` 来源清单，原始文件名和目录完整保留。

首次全量归档进行中。分类索引会列出实际归档数量和下载失败项；候选清单不代表全部下载成功。
